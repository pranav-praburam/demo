## 4. How to Produce It

1. **Characters:** Use an image model that supports a reference image (Higgsfield, Midjourney `--cref`, Leonardo, or Ideogram). Upload Pic 1, use the Section 2 prompts and erase the handbag (inpaint / generative fill). Export transparent PNGs.
2. **Backgrounds:** Generate each scene background with the prompts above (always add "no text" so the AI doesn't draw fake letters).
3. **Animate:** Turn each still into a 5–8 s clip with an image-to-video model (Kling, Runway Gen-4, Higgsfield, Luma) using the motion prompts.
4. **Tamil text:** **Add all Tamil text in the editor (CapCut, Canva, Premiere or After Effects), never through the AI.** AI generators garble Tamil script. Copy the verses straight from this file.
5. **Edit:** Put the clips together in order, with 0.5 s petal or light-leak transitions, the music track and gold-dust overlays. Export 1080×1920 MP4 at 30 fps.
